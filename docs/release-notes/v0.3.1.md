# mai2srt v0.3.1

补丁版本：加固大文件分块与压缩，并补齐大模型断句的超时控制。存储格式、命令行用法和现有配置保持兼容，可直接覆盖安装。

## 媒体分块与压缩

- MP3 CBR 码率只取标准 MPEG-1 档位并封顶 128 kbps，避免 libmp3lame 取整后越过 25 MiB 上传上限。
- 单文件与分块上传共用同一条编码路径：逐级降低码率重新编码、去除元数据（`-map_metadata -1`）、静音切点取中点、限制静音搜索窗口；分块仍超限时递归再切。
- 压缩后的分块大小更可预测，减少上传阶段因超出站点限制而失败重试。

## 大模型断句与超时

- 摘要输入预算（40k 字符）与断句批预算（6k 字符）拆开，避免摘要挤占断句批次。
- 批处理超时后把多段批次快速拆小，并把收紧后的批上限沿用到后续批次。
- 新增供应商超时设置：10–1800 秒，显式传 `null` 恢复默认 120 秒；贯通后端 API、旧版镜像同步、连通性探测和「设置 → 大模型」界面。

## 验证

## 安装

- **Windows**：下载 `mai2srt_0.3.1_x64-setup.exe`，可直接覆盖安装，FFmpeg 已随包内置。首次安装可能出现 Windows SmartScreen 蓝窗（安装包未签名）→ 点「更多信息」→「仍要运行」。用户数据保存在 `~/.mai2srt`，覆盖安装与卸载不会删除。

## English

Patch release: harder guarantees around chunking and compression for large files, plus timeout controls for LLM segmentation. Storage format, CLI usage and existing configuration remain compatible; install over the previous version.

## Media chunking and compression

- MP3 CBR bitrate is restricted to standard MPEG-1 tiers and capped at 128 kbps, so libmp3lame rounding can no longer push a chunk past the 25 MiB upload limit.
- Single-file and chunk uploads now share one encoding path: strict step-down re-encoding, metadata stripping (`-map_metadata -1`), midpoint silence cuts, a bounded silence search window, and recursive splitting when a chunk is still too large.
- Compressed chunk sizes are more predictable, reducing upload-stage retries caused by exceeding the site limit.

## LLM segmentation and timeouts

- The summary input budget (40k characters) is separated from the segmentation batch budget (6k characters), so a summary no longer competes with the segmentation batch.
- On a batch timeout, multi-segment batches are split quickly and the tightened cap is propagated to subsequent batches.
- New provider timeout setting: 10–1800 seconds; an explicit `null` resets the 120-second default. It is wired through the backend API, legacy mirror sync, connectivity probes and Settings → LLM.

## Verification

- The changes are covered by `tests/test_m1_pure.py`, `tests/test_m5_server.py`, `tests/test_m6_protocol.py` and `tests/test_m6d_llm_split.py`.
- Windows and Linux installers are built by GitHub Actions; the pipeline runs the full backend test suite before packaging and smoke-tests that the frozen backend starts.

## Install

- **Windows**: download `mai2srt_0.3.1_x64-setup.exe`; it installs over the previous version, FFmpeg included. A first install may show the Windows SmartScreen prompt (the installer is unsigned) → "More info" → "Run anyway". User data lives in `~/.mai2srt` and survives upgrades and uninstalls.
- **Linux**: install the `.deb` with `sudo apt install ./mai2srt_0.3.1_amd64.deb` (FFmpeg is pulled in as a dependency); the AppImage needs system FFmpeg (`ffmpeg` and `ffprobe` on `PATH`) and the WebKitGTK 4.1 runtime, then `chmod +x` and run.

`SHA256SUMS.txt` in the release assets can verify the downloads.
